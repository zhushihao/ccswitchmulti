# CCSwitchMulti v3.19.2-18.4

## 修复

- 修复 macOS 正常退出被误判为异常退出：原先读取进程身份使用了仅 Linux 存在的 `/proc` 路径，苹果系统读不到后会把正常关闭当成崩溃处理。本版改用 macOS 原生接口读取可执行路径和进程启动时间，正常退出不再触发崩溃恢复告警。
- 修复正常退出删除唯一 Live 备份导致配置丢失：退出时仍启用代理接管的应用会保留一份干净备份，供下次启动自动接管与恢复使用；只有手动关闭接管的应用才会删除备份，避免长期保存敏感登录材料。
- 修复恢复配置时丢失用户字段：备份缺失或备份已是代理占位符时，从当前供应商重建一份干净备份；崩溃后恢复优先从备份完整还原 Claude/Codex 等应用的用户配置（如权限、项目范围、MCP 等），不再直接提示 `userTables` 丢失。
- 统一应用内“检查更新”、托盘官网链接和 Windows 发布导出脚本指向 fork 仓库 `zhushihao/ccswitchmulti`。

## 说明

- 本版保留母仓库 v3.19.2-18、fork 插件注册修复和 profile provider 快照同步修复。
