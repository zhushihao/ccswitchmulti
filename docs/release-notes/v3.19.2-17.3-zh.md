# CCSwitchMulti v3.19.2-17.3

## 修复

- **数据库 v18 兼容回归**：本版基于 `v3.19.2-17.1` 的完整数据库迁移重新发布，重新支持 `v16 → v18`，不再把已经由 17.1 升级的数据库误判为“版本过新”。
- **项目供应商快照自动同步**：切换设备级供应商后，当前项目的供应商快照会同步到新供应商，同时保留项目已有的 MCP、Skills 和 Prompt 配置，避免 Codex 继续使用旧路由。

## 背景

`v3.19.2-17.2` 使用的发布分支包含旧数据库 schema `v16`，而本机数据库已经由 `v3.19.2-17.1` 升级到 `v18`，因此打开应用时会显示“数据库版本过新”，并且升级检查认定当前已是最新版本，无法自动修复。本版已改用正确的发布基线。
